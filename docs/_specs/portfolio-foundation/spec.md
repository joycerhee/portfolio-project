# Portfolio Foundation Spec

## Problem
Build an aspirational professional portfolio that communicates a clear direction in front-end development and UX research with a focus on digital accessibility.

## Target Audience
Product team leads at mid-size companies hiring a junior front-end developer with UX research skills and accessibility expertise.

## Design Goals
- Warm, editorial Caregiver archetype — approachable, human, trustworthy
- Snug Simple design trend with cream/beige palette and warm brown accents
- Serif headings, sans-serif body — editorial feel
- One-page layout with smooth scroll navigation and modals for project details
- Contact form for direct outreach

## Brand Archetype
Caregiver — focused on making digital products work for everyone, especially users who are often overlooked in accessibility.

## Sections
- Hero with professional promise and audience tag
- About me with photo
- Selected Work with 3 clickable project cards and modals
- Skills and tools
- How I Work process
- Contact form with email, GitHub, LinkedIn
- Footer

## AI Tools
- GitHub Copilot for scaffolding and implementation
- Claude for content strategy, design direction, and code review
- Lovable for visual design and dynamic features

## Verification
- Site loads without errors
- All sections render correctly
- Modals open and close properly
- Smooth scroll navigation works
- Contact form triggers mailto
- Deploys to GitHub Pages
